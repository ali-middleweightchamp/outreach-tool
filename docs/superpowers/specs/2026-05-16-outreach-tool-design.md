# Дизайн: B2B Outreach Tool

**Дата:** 2026-05-16  
**Цель:** Тестовое задание для аутрич-агентства. Система для обогащения базы B2B компаний контактами и персонализацией.

---

## Архитектура

Два независимых скрипта, выполняемых последовательно вручную:

```
companies.csv → [scraper.py] → contacts.csv → [personalization.py] → contacts.csv (обогащённый)
```

### Технологический стек

- **Скрапинг:** `requests` + `BeautifulSoup4` (только статический HTML, без JavaScript)
- **Прогресс:** `tqdm`
- **Claude API:** `anthropic` SDK
- **Масштаб:** 50–200 компаний

## Файлы

### companies.csv

| Колонка   | Описание              |
|-----------|-----------------------|
| Компания  | Название компании     |
| Сайт      | URL (с https://)      |

### contacts.csv

| Колонка    | Описание                               |
|------------|----------------------------------------|
| Компания   | Из companies.csv                       |
| Сайт       | Из companies.csv                       |
| Email      | Найденный email или пусто              |
| Имя_ЛПР   | Имя лица, принимающего решения или пусто |
| Должность  | Должность ЛПР или пусто               |

После personalization.py добавляется:

| Колонка        | Описание                         |
|----------------|----------------------------------|
| Персонализация | 1-2 предложения от Claude API    |

## scraper.py — детальный дизайн

### Алгоритм

1. Читает `companies.csv`
2. Загружает уже обработанные компании из `contacts.csv` (чекпоинтинг — пропускает их)
3. Для каждой необработанной компании:
   a. Запрашивает главную страницу (таймаут 10 сек)
   b. Ищет email через regex с приоритетом: `info@`, `sales@`, `hello@`, `contact@`; fallback — первый найденный email
   c. Пробует дополнительные страницы в порядке: `/about`, `/about-us`, `/team`, `/о-компании`, `/команда`
   d. Ищет ЛПР: regex-шаблон «Имя Фамилия» рядом с должностью (CEO, Director, Founder, Директор, Генеральный и т.д.)
   e. Ждёт `random.uniform(2, 3)` секунды
   f. Добавляет строку в `contacts.csv`
4. Прогресс-бар через `tqdm`

### Обработка ошибок

- `requests.exceptions.RequestException` — пишет `ошибка` в `Статус`, продолжает
- `ConnectionError`, `Timeout` — то же самое
- Перехватывает все исключения через `except Exception` — не падает никогда

## personalization.py — детальный дизайн

### Алгоритм

1. Читает `contacts.csv`
2. Для каждой строки:
   a. Запрашивает главную страницу компании (таймаут 10 сек)
   b. Извлекает текст (`soup.get_text()`), обрезает до 3000 символов
   c. Вызывает Claude API:
      - Модель: `claude-sonnet-4-20250514` (как указано в задании)
      - Системный промпт: «Ты помощник для B2B аутрича. На основе текста сайта напиши 1-2 предложения персонализации для холодного письма. Только реальные факты с сайта. Без общих фраз. На русском языке.»
      - `max_tokens: 200`
   d. Пишет результат в колонку `Персонализация`
   e. Ждёт `random.uniform(2, 3)` секунды
3. Перезаписывает `contacts.csv`

### Конфигурация

- API ключ: переменная окружения `ANTHROPIC_API_KEY`
- При отсутствии ключа — выводит понятную ошибку и выходит

### Обработка ошибок

- Сайт недоступен — пустая строка в `Персонализация`, продолжает
- API ошибка — пустая строка, логирует в консоль, продолжает

## Решения и компромиссы

| Решение | Причина |
|---------|---------|
| Статический HTML | Простота, достаточно для большинства B2B сайтов |
| Чекпоинтинг через CSV | Возобновление без лишней зависимости (SQLite) |
| Обрезка до 3000 символов | Баланс качества и стоимости API |
| `random.uniform(2, 3)` | Снижает риск бана при имитации человеческого поведения |
| Два отдельных скрипта | Независимый запуск, легко отлаживать по частям |
